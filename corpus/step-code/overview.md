# Step Code Overview

Step Code is a terminal-based AI agent for reading and changing code, running commands, and completing software development tasks.

## Get Started

* [Installation & Quickstart](/docs/en/step-code/quickstart)
* [Authentication and model selection](/docs/en/step-code/configuration/models)

Installation supports macOS and Linux. Windows PowerShell support is in beta; WSL is recommended on Windows. See the quickstart for requirements.

## API and Step Plan

Step Code is a developer tool that can access models through subscription login or an API key. [Step Plan](/docs/en/step-plan/overview) covers subscription rules, while [Platforms and Models](/docs/en/step-code/configuration/models) is the shared reference for Step Code authentication and billing channels. For direct model API calls, use the [API Quickstart](/docs/en/quickstart/overview).
